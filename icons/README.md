# Extension Icons

This directory contains the icons for the LinkedIn Outreach Manager extension.

## Generating Icons

Since we don't have image processing tools available, you can:

1. Use the `icon.svg` file as a template
2. Convert it to PNG files using an online tool or local software:
   - icon16.png (16x16 pixels)
   - icon48.png (48x48 pixels)
   - icon128.png (128x128 pixels)

3. Or use an online SVG to PNG converter like:
   - https://svgtopng.com/
   - https://cloudconvert.com/svg-to-png

## Temporary Solution

For testing purposes, you can use any 16x16, 48x48, and 128x128 PNG images.
The extension will work with placeholder images.

## Design

The icons feature a LinkedIn blue gradient background (#0077b5 to #00a0dc) 
with white "LO" letters (LinkedIn Outreach) centered.
